# Shadow Transfer v0.1.0

**Transfer Without Limits.** First public release of the secure local-network file transfer app for Windows and Android, powered by a shared Rust engine.

## Highlights

- TLS 1.3-only transport with mutual certificates and SHA-256 certificate-fingerprint pinning.
- Standalone pairing with one-time 8-character codes, explicit receiver approval, rate limiting and replay-resistant BLAKE3 proofs.
- Streaming file and folder transfer with per-chunk and full-file BLAKE3 verification.
- Resume from a verified prefix after cancellation or connection loss.
- Never overwrites existing files; received files are never executed.
- Separate automatic discovery and manual connection flows with a dedicated pairing action.
- Windows egui application with drag-and-drop, queue, live speed/ETA, history and settings.
- Android Compose application with SAF destination import, foreground data-sync service and transfer approvals.
- 47 automated tests, including real TCP/TLS/filesystem end-to-end coverage.

## Quick start

1. Install the app on Windows and Android; allow Shadow Transfer on private networks in the Windows firewall.
2. On the receiver, enable **Receive** and note the pairing code.
3. On the sender, use **AUTO DISCOVERY** or the separate **MANUAL CONNECTION** card, enter the code, and press **Pair**.
4. Approve the pairing request on the receiver.
5. Choose files/folders, press **Send**, and approve the incoming transfer.

Port `47831/TCP` is used for transfer and `47830/UDP` for discovery. Both devices must be on the same LAN, without client isolation or a blocking VPN.

## Validation

- 47 automated tests pass (`cargo fmt`, `clippy -D warnings`, `cargo test --workspace`).
- Real Windows → Samsung Galaxy Tab A7 (SM-T505) transfers of 449 MB and 1.845 GB completed and were BLAKE3-verified.
- Loopback after speed tuning: 5 GiB at 324.9 MiB/s; 100 MiB up to ~490 MiB/s.
- Real Wi-Fi throughput on the test 5 GHz link was ~15 MB/s and is link-bound.

## Known limitations

- Android identity keys are not yet Keystore-wrapped; Windows keys are not DPAPI-wrapped.
- No code signing for Windows binaries or Play Store provenance for the APK.
- IPv4 LAN only; no QR pairing, compression, QUIC or parallel streams.
- Automated tests are host-side; Android device testing is manual.
- Latest speed-tuning APK/EXE needs a repeat real-device throughput test.
